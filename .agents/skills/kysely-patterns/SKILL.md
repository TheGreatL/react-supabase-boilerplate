# Kysely Patterns Skill

This skill provides comprehensive instructions for AI agents on how to interact with the project's database layer using **Kysely**.

## 🎯 Goal
Ensure 100% type-safe database operations that strictly follow the project's Repository pattern and soft-delete conventions.

## 🛠️ Core Principles
1. **Never use Prisma**: All Prisma dependencies have been removed. Use Kysely `db` for all database interactions.
2. **Type Safety First**: Always use the generated types from `@/shared/types/db`.
3. **Soft Delete Compliance**: Every retrieval query (SELECT) must include the `where(active)` filter unless explicitly asked to include deleted records (e.g., for data recovery).
4. **Transaction Integrity**: Use Kysely transactions for operations affecting multiple tables.

## 📝 Query Patterns

### SELECT with Soft-Delete
```typescript
import { db } from '@/shared/lib/db';
import { active } from '@/shared/lib/db-utils';

const results = await db
  .selectFrom('table_name')
  .selectAll()
  .where(active) // MANDATORY for standard lookups
  .execute();
```

### INSERT with Auto-ID
Most tables use UUIDs generated by the application or database.
```typescript
import { db } from '@/shared/lib/db';
import { Insertable } from 'kysely';
import { User } from '@/shared/types/db';

const newUser: Insertable<User> = {
  id: crypto.randomUUID(),
  email: 'test@example.com',
  // ...
};

await db.insertInto('user').values(newUser).execute();
```

### Complex Aggregations
```typescript
const stats = await db
  .selectFrom('user')
  .select((eb) => [
    'role',
    eb.fn.count('id').as('userCount')
  ])
  .where(active)
  .groupBy('role')
  .execute();
```

## 🔄 Migration Guideline
When a user asks to "add a field" or "create a table":
1. **Create Migration**: Use `npx kysely migrate:make <name>`.
2. **Edit Migration**: Define the schema change in the generated file.
3. **Execute**: Run `npm run db:migrate`.
4. **Regenerate Types**: Run `npm run db:generate` IMMEDIATELY to sync the TypeScript types.

## ⚠️ Common Pitfalls
- **Forgetting `active`**: Forgetting to filter by `deletedAt is null` will return archived data, breaking business logic.
- **Manual Interfaces**: Never write manual interfaces for database tables. Use `Selectable<T>`, `Insertable<T>`, and `Updateable<T>` from the generated `DB` type.
- **Direct Express DB access**: Never put DB queries in Controllers. Always use the Repository layer.
